Income Classification from U.S. Census Data

This project predicts whether an individual earns >50K per year based on U.S. Census demographic and employment features (age, workclass, education, marital status, occupation, hours worked, etc.). The prediction target is binary (<=50K vs >50K). We will build baseline and progressively more complex machine learning models and evaluate them for accuracy, fairness, and interpretability.

Python scikit-learn pandas matplotlib Jupyter Notebooks
More details

Problem

Income inequality remains a central topic in social and economic research. Predicting income brackets from census data highlights structural relationships between education, occupation, and demographic variables. Prior studies on the UCI Adult dataset show that while linear models achieve moderate accuracy, ensemble methods often perform better by capturing nonlinear dependencies. This project combines statistical rigor with interpretability to showcase responsible machine learning. This problem is important because income level is strongly tied to access to healthcare, housing stability, educational opportunities, and long-term economic mobility. Understanding which socioeconomic factors predict higher income can support policymakers, nonprofits, and labor economists in identifying structural inequalities and potential intervention points. Organizations concerned with economic justice and social mobility care deeply about improving predictive tools that reveal disparities in opportunity.

Approach

Collected location data across 47 candidate nap sites over a full academic semester. Features included average daily sunlight (hours), grass softness score (1–10, assessed manually), nearby food-cart proximity, and pedestrian traffic by hour. Trained a gradient boosting classifier to predict a site's "nap quality" rating and used SHAP values to explain which features mattered most.

Results & Impact

Overall, the desired performance goals were met, with Gradient Boosting surpassing the baseline by a significant margin and offering interpretable insights into which socioeconomic variables most influence income level. Some challenges arose during preprocessing and training, particularly with high-cardinality categorical variables and slow convergence in logistic regression. Future work could include hyperparameter tuning for all models, exploring XGBoost for faster training, applying techniques to address class imbalance (such as SMOTE or class-weighting), and conducting a deeper fairness analysis to examine whether model performance differs across demographic groups.

NFL Game Outcome Prediction Using Team Performance Metrics

Built machine learning models to predict NFL game outcomes and point differentials using team-level performance statistics. Engineered rolling features to capture recent team form and compared Logistic Regression and Random Forest models to evaluate predictive performance.

Python pandas scikit-learn matplotlib great_tables Jupyter Notebooks
More details

Problem

Predicting NFL game outcomes is challenging due to variability in team performance, injuries, and game context. The goal of this project was to determine whether recent team performance metrics — such as offensive efficiency, defensive strength, and turnover rates — can be used to reliably predict game winners and point differentials.

Approach

Collected NFL play-by-play data using nfl_data_py and aggregated it to the team-game level. Engineered rolling statistics over the previous 10 games (e.g., EPA per play, success rate, point differential, and turnovers) to capture recent team performance. Created matchup features by taking differences between home and away teams (e.g., home − away). Trained both Logistic Regression and Random Forest classifiers to predict game outcomes, and a regression model to predict point differentials. Evaluated models using accuracy and ROC-AUC, and visualized results using Great Tables and matplotlib.

Results & Impact

Logistic Regression performed competitively with — and in some cases outperformed — Random Forest, suggesting that the engineered difference features capture much of the underlying signal in a linear form. The model achieved strong predictive performance on test data and provided interpretable insights into which factors most influence game outcomes. Team-specific analysis (e.g., Detroit Lions) revealed that the model tends to overestimate strong teams, highlighting the limitations of purely statistical approaches in accounting for game-level randomness and contextual factors.

Predicting NYC 311 Complaint Resolution Time Using AWS SageMaker

Developed a machine learning pipeline on AWS to predict how long NYC 311 service requests will take to resolve. Built end-to-end workflow using Athena, S3, and SageMaker Linear Learner, transforming raw complaint data into a structured modeling dataset for scalable training.

Python pandas scikit-learn AWS S3 AWS Athena AWS SageMaker (Linear Learner) SQL Jupyter Notebooks
More details

Problem

NYC 311 receives thousands of service requests daily, but resolution times vary widely depending on agency, location, and request type. The goal of this project was to predict the number of days required to resolve a complaint at the time it is submitted, enabling better resource planning and expectation management.

Approach

Queried raw complaint data from AWS Athena and stored datasets in S3. Cleaned and transformed the data into a modeling-ready format, including handling missing values and encoding categorical variables (agency, borough, complaint type). Engineered time-based features such as day of week and hour of day, as well as operational features like same-day complaint volume. Converted the target variable (days_to_close) into both regression and binary classification formats. Prepared data according to SageMaker requirements (label-first, no headers, numeric-only) and trained a Linear Learner model using S3-hosted training data.

Results & Impact

The model successfully captured patterns in resolution time based on agency workload and temporal features. Results demonstrated that simple linear models can perform effectively when features are carefully engineered and properly formatted for scalable systems. The project highlighted the importance of data preprocessing and cloud-based workflows for handling large datasets, as well as the tradeoffs between model simplicity and interpretability in production environments.
